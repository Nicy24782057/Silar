Fungsi setiap folder

Folder ini memuat apa?

Notebook akhir ada di notebooks/, notebook lama di historical/, hasil terbaru di reports/, dan bukti mentah di evidence/. Setiap folder utama mempunyai satu README dengan penjelasan khusus isinya.

FolderIsi
notebooks/Notebook final 29–32 beserta keluaran eksekusinya: training, verifikasi ekspor, uji FINAL084 dan keputusan batas 6%.
historical/Notebook lama, dikelompokkan menurut tahap/versi. Satu README menjelaskan seluruh kelompoknya.
reports/Hasil terbaru SENA, NARA, field dan keputusan FINAL084; metrics_summary.json memuat angka beserta sumbernya.
code/Implementasi runtime, adapter, training, importer/evaluator dan pengujian.
config/Konfigurasi, lock model, requirements dan keputusan cutoff. Versi config final adalah v0.9; pipeline v0.8.4.
data/Data training/development, proposal acuan, identitas split dan catatan retirement putaran lama.
acceptance/Workbook review manusia dan protokol penerimaan. Workbook FINAL084 yang diuji memakai nama v0_8_4.
evidence/Bukti mentah training/pengujian: log, prediksi, acuan beku, snapshot sumber, metrik asli dan revisi keputusan.
results/Laporan, Excel, grafik dan hasil olahan eksperimen sebelum FINAL084.
sources/ZIP laporan asal, dokumen acuan proyek dan sumber review. Notebook asalnya dikelompokkan di historical.
nara_finetune_frozen/Kode, data dan split fine-tune NARA reviewed pilot yang dibekukan.
examples/Tiga narasi sintetis untuk smoke test pemuatan; bukan data uji penerimaan terbaru.
docs/Tiga laporan teknis awal tentang evaluasi NARA dan kondisi sebelum fine-tune SENA.
