## Bukti Pekerjaan

Implementasi SLR12 mencakup pemeriksaan dan koreksi hasil, riwayat versi, Human Verification, pengiriman resmi, notifikasi Reporter serta penyempurnaan identitas visual dan tema. Bukti fungsi utama menggunakan arsip implementasi awal SLR12; bukti penyempurnaan frontend menggunakan revisi UI sampai v0.4.3.

| Bagian pekerjaan | Bukti implementasi/verifikasi |
| --- | --- |
| API koreksi, Human Verification, submit dan riwayat | `code/backend/reporting/review_services.py`, `review_views.py`, `review_serializers.py` dan `urls.py`. Mencakup versi baru, konfirmasi terikat versi aktif, penguncian versi resmi, audit dan laporan SUBMITTED yang dapat dibaca pada scope antrean pengelolaan. |
| Antarmuka pemeriksaan dan pemulihan | `code/frontend/src/components/ReportReview.vue`, `VersionHistory.vue`, `ReportCardPreview.vue` serta `code/frontend/src/views/DraftView.vue` dan `ReportsView.vue`. Mencakup perbandingan hasil/sumber, koreksi, riwayat, daftar/detail, pemulihan baca serta tahap konfirmasi dan kirim yang terpisah. |
| Guard, kepemilikan dan konsistensi tindakan | Tes pada `code/backend/reporting/tests/test_review.py`, `test_review_pipeline.py` dan `test_review_postgresql.py`. Cakupan mencakup NON_EVENT/uncertain, sumber berubah, konfirmasi ulang, replay, revision/parent usang, pemilik lain, rollback, pembacaan riwayat aman serta operasi bersamaan. Hasil dan batas pelaksanaan tercatat pada `docs/slr12/HASIL_VERIFIKASI.md`. |
| Notifikasi dalam aplikasi | Layanan bersama `code/backend/core/notifications.py`, API pada `code/backend/reporting/review_views.py`, serta `code/frontend/src/views/NotificationsView.vue`. Daftar dibatasi penerima, mendukung pagination/filter dan penandaan dibaca. Event pengiriman disimpan bersama transaksi submit; pemicu pemeriksaan/publikasi dilengkapi SLR13–SLR14. |
| Logo, tema bersama, akun dan PWA | Kerangka `code/frontend/src/App.vue`, token/perilaku tema pada `src/theme.css` dan `src/theme.js`, gaya bersama `src/ui.css` dan `src/reports-ui.css`, serta halaman akun `src/views/AuthView.vue` dengan `src/auth-ui.css` dan `src/assets/auth-identity.svg`. Logo navigasi memakai `public/brand/silar-logo.png`; pengelolaan aset/cache PWA mengikuti `vite.config.js` dan `tools/service-worker.js`. |
| Verifikasi fungsi SLR12 sebelumnya | Arsip mencatat **53 tes backend komponen lulus**, termasuk 24 regresi input, 27 API SLR12 dan dua sambungan revisi narasi-pipeline dengan provider pengganti. Bukti: `docs/slr12/bukti-uji/backend-komponen.txt`. Kelulusan **34 tes pada clone Windows** yang dikirim pengguna dicatat terpisah pada `backend-windows-ringkasan-pengguna.txt`; angka tersebut bukan tambahan tes independen yang dijumlahkan dengan 53 tes komponen. |
| Verifikasi UI v0.4.3 | **73 tes frontend/PWA lulus**, **54 skenario browser development lulus**, **3 pemeriksaan browser build produksi lulus**, dan build berhasil dengan **68 modul**. Ringkasan: `docs/slr12/HASIL_VERIFIKASI_UI_v0.4.3.md`; log: `docs/slr12/bukti-uji/ui-v0.4.3/`. |
| Dokumentasi operasional dan perubahan | Panduan menjalankan aplikasi tetap satu dokumen di root, `PANDUAN_RUNNING.md`. Daftar file/hash revisi UI tersedia pada `docs/slr12/ui-v0.4.3/DAFTAR_PERUBAHAN.json`. |

**Catatan lingkup bukti:** Pengujian komponen dan browser pada lingkungan penyusunan paket menggunakan SQLite terisolasi, akun/laporan sintetis serta hasil analisis fixture/provider pengganti sesuai skenario. Inferensi tujuh rute dan model nyata tidak diulang pada revisi UI. Hasil 34 tes Windows merupakan laporan pengguna. Pengguna juga telah mengonfirmasi perubahan logo Chrome/PWA setelah hard refresh; instalasi PWA baru pada perangkat fisik tidak diklaim sebagai pengujian tambahan. Bukti visual awal berada pada arsip `docs/slr12/bukti-uji/`; pengujian responsif memakai viewport browser sesuai laporan masing-masing versi.

**Commit SHA/URL:** ditambahkan oleh kelompok.
