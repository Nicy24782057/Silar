PEMASANGAN
1. Hentikan backend dan frontend. Pertahankan perubahan lokal tim.
2. Ekstrak ZIP ke folder sementara. Gabungkan code/ dan docs/slr14/ ke clone
   Silar yang sudah menjalankan SLR13, berdasarkan path. Timpa hanya berkas
   yang disertakan. Jangan mengganti/menghapus seluruh folder code.
3. Pada terminal code/backend (konfigurasi SLR13/PostgreSQL 16 yang sudah aktif):

   .\.venv\Scripts\python.exe manage.py migrate
   .\.venv\Scripts\python.exe manage.py check
   .\.venv\Scripts\python.exe verify_slr14.py
   .\.venv\Scripts\python.exe manage.py runserver localhost:8001

4. Pada terminal code/frontend:

   npm.cmd test
   npm.cmd run build
   npm.cmd run dev

   Gunakan npm.cmd ci jika dependensi belum tersedia.
5. Jika memilih alternatif patch, gunakan git apply --check dahulu pada base
   yang sesuai, lalu git apply. Jangan memasang patch DAN menimpa berkas secara
   bergantian. Lihat docs/slr14/README.md untuk penjelasan lengkap.
