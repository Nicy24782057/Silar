CARA MEMASANG
1. Hentikan frontend. Ekstrak ZIP ini ke folder sementara.
2. Gabungkan berkas sesuai path ke clone Silar yang sudah berisi paket terakhir.
   Jangan mengganti seluruh folder repository.
3. Dari code/frontend, jalankan:
   npm.cmd test
   npm.cmd run build
   npm.cmd run dev
4. Buka ulang halaman. PWA produksi perlu menerima pembaruan melalui
   Aplikasi & Koneksi, lalu dibuka kembali. Backend dijalankan seperti biasa.

YANG BERUBAH
- Header akun HP memakai biru SILAR, logo, pattern dan ilustrasi desktop asli.
- Panel formulir melengkung mengikuti pratinjau SVG yang telah disetujui.
- Header registrasi, OTP, aktivasi dan pemulihan lebih pendek: form lebih tinggi.
- Layar pembuka browser HP/PWA minimum sekitar 1,2 detik, termasuk penyiapan.
  Tidak diputar ulang pada navigasi antarhalaman di dalam aplikasi.
- Dua panel desktop/tablet tetap tampil mulai lebar 641 piksel.
- Sesi valid tetap menawarkan Buka aplikasi pada landing tanpa login ulang.

YANG PERLU DICOBA
1. Pada HP, buka /login melalui browser. Periksa layar pembuka dan login baru.
2. Buka Buat akun dan Verifikasi akun: formulir mulai lebih tinggi.
3. Gulir sampai tombol terakhir, termasuk pada layar pendek atau keyboard terbuka.
4. Periksa terang/gelap, ikon mata dan tidak ada gambar/kolom bertumpuk.
5. Coba daftar/kode, aktivasi Operator, lupa sandi dan penyimpanan sandi baru.
6. Pada desktop/tablet, pastikan kedua panel masih tampil.
7. Login, buka landing lalu Buka aplikasi; coba muat ulang dengan sesi valid.
